# M1 需求边界与验收标准

> 项目：Desktop Organizer（个人自用 Windows 桌面整理工具）
> 版本：v0.1 | 冻结日期：2026-11-02 | 负责人：lead

## 1. 一句话定位

把桌面（或用户指定的任意目录）堆积的文件，按 **类别 / 重要程度 / 使用频次** 整理成 `类别/重要度/` 的两层文件夹结构。放置策略由本地规则引擎给出建议，**人逐项确认或一键采纳**，每次改判被记住并影响下次建议。

**它不是**：文件清理器（不删文件）、磁盘分析工具、云盘同步工具、跨机同步工具。

## 2. 使用边界（In Scope）

| 维度 | 界定 |
|---|---|
| 操作系统 | Windows 10 / 11，单用户单机 |
| 整理范围 | 一个根目录 + `max_depth` 层（默认只看第一层，不递归进子目录） |
| 文件类型 | 常规文件；目录只报不移动（v0.1 不整理文件夹） |
| 交互形态 | CLI（脚本化/可测） + tkinter 轻量 GUI（人工确认） |
| 数据来源 | 本地文件系统元数据（名/扩展名/大小/时间/属性） |
| 智能来源 | 本地规则引擎（扩展名 + 关键词 + 时间 + 大小）+ 用户改判沉淀；不联网、不调用外部模型 |

## 3. 明确不做（Out of Scope）

- ❌ 删除任何文件（产品内不存在 delete 代码路径）
- ❌ 递归整盘扫描、自动后台常驻监控
- ❌ 真实桌面写入（除非用户将来手动把 `ALLOW_USER_DIRS` 改为 True —— 本会话永不开启）
- ❌ 云端大模型调用、联网、账号体系
- ❌ 多用户、多机同步、移动端
- ❌ 撤销"撤销"（不做无限历史，只保留最近 N 个 journal）
- ❌ 文件夹整体归档（v0.1 只处理文件；目录只在报告中列出）

## 4. 用户故事

| ID | 故事 | 验收 |
|---|---|---|
| US1 | 我把桌面截图、下载的 PDF、压缩包堆一起，想一键看会怎么整理 | 默认 dry-run，扫描后给出预览表，不动任何文件 |
| US2 | 我想逐项确认，不同意的那条能改成别的类别 | 每条建议可改类别/重要度，改后立即生效于 plan |
| US3 | 我想一键采纳所有高置信建议 | 高置信（≥0.80）可批量采纳，中/低置信必须逐条确认 |
| US4 | 我上次把 .png 改到了"设计稿"，下次它该记住 | 同一扩展名第二起直接被建议到"设计稿"，置信度 0.95 |
| US5 | 我执行完后悔了，要一键恢复原样 | 回滚命令把所有已移动文件移回原位，失败条目单独报告 |
| US6 | 整理到一半电脑蓝屏了 | 重新启动后能看到未完成的 journal，可回滚到一致状态 |
| US7 | 我不想它碰我的 OneDrive 占位文件 | 云占位文件一律跳过，在报告里单独列出"已跳过" |

## 5. 三条硬指标与验收方法

### NFR1 轻量
| 指标 | 目标 | 实测方法 |
|---|---|---|
| 冷启动（CLI `--version`） | < 2s | `Measure-Command { python -m desktop_organizer --version }`，取 5 次中位数 |
| 冷启动（GUI 首帧） | < 2s | 记录进程启动到窗口可见的时长（脚本打点） |
| 常驻内存（GUI 空闲） | < 120 MB | `Get-Process` WorkingSet64 |
| 第三方运行时依赖 | 0 个 | `pip list` 对照；只有 stdlib + tkinter |
| 安装包体积 | 实测出数，< 60 MB | PyInstaller --onedir 产物体积 `du` |

### NFR2 可靠
| 指标 | 目标 | 实测方法 |
|---|---|---|
| 默认 dry-run | 无参数调用不写盘 | 沙箱快照（文件数 + 全量 mtime 哈希）前后一致 |
| 移动可回滚 | 100% 可回滚 | 每完成一个 plan 立刻 rollback，比对快照 |
| 不丢文件 | 0 丢失 | 执行前后总字节数 + 逐文件哈希一致（除已知失败项） |
| 中断可恢复 | journal 可重放 | 注入异常模拟崩溃，验证一致状态可达 |
| 冲突不覆盖 | 永不覆盖 | 目标同名文件自动追加 ` (n)` |

### NFR3 可控
| 指标 | 目标 | 实测方法 |
|---|---|---|
| AI 只出建议 | 无用户确认不执行 | 代码审查：execute 必须有显式 plan + 非 dry_run 标记 |
| 改判可沉淀 | 二次同类自动生效 | 单测：remember 后 lookup 返回用户选择 |
| 偏好可见可改 | 偏好文件人可读可编辑 | JSON 明文，字段有注释文档 |

## 6. 安全红线（优先级高于一切功能）

1. **写盘前必过 guard**：`guard.assert_safe()` 是唯一入口，黑名单硬编码，无 CLI 开关可绕过。
2. **系统目录永不触碰**：Windows / Program Files / AppData / ProgramData / 回收站 / 系统盘根 / UNC。
3. **用户数据目录默认拒绝**：Desktop / Documents / Downloads / OneDrive 默认全部拒绝写入。
4. **云占位文件只读不碰**。
5. **本会话所有测试只在 sandbox/**。
